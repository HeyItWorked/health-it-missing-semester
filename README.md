# Health IT Missing Semester

A seven-week, hands-on self-study course for new computer-science graduates heading into healthcare IT in the US and Canada, in the format of MIT's [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/).

**Read it:** https://heyitworked.github.io/health-it-missing-semester/ (or open `index.html` locally; there is no build step).

## What's inside

| Week | Topic |
|---|---|
| 0 | Stack short runs: one FHIR kata in Java, C#, Python and TypeScript |
| 1 | How care works |
| 2 | Data + SQL |
| 3 | HL7 v2 + patient identity |
| 4 | FHIR APIs |
| 5 | Privacy + AI |
| 6 | Ship + get hired |

Also: prework, lab setup, US vs Canada, interview prep, what you'll learn on the job, a glossary and must-read book chapters. Each week's lab files are in `static/files/week-N/`. Every terminal session on the pages was run against the course lab on 31 Oct 2026, using synthetic data only.

This is educational material. It is not legal, compliance or medical advice.
