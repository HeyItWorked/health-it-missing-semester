Glossary

Short definitions of terms used across the course. In week 1 you start your own glossary.

TermMeaning
ACKReply to an HL7 v2 message: AA accept, AE error, AR reject
ADTAdmit/discharge/transfer messages about patient movement
BAAHIPAA contract with a vendor that handles PHI
C-CDAThe main US clinical-document format
EMPIEnterprise index linking one person's MRNs
FHIRHL7's REST API standard for health data
HAPIOpen-source Java FHIR and HL7 v2 libraries and server
LOINCCodes for lab tests and observations
MLLPHL7 v2's framing over TCP
MRNMedical record number, issued per facility
OCAP®First Nations principles: ownership, control, access, possession
OIEOpen Integration Engine, the open fork of Mirth Connect
PHIProtected (US) or personal (Canada) health information
RxNormUS normalized drug concepts
SMART on FHIRApp-launch and OAuth profile for FHIR
SNOMED CTClinical terminology for findings and procedures
TEFCAUS national framework for health information exchange
Z-segmentSite-defined HL7 v2 segment; its name starts with Z
