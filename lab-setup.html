Lab setup

All run on 31 Oct 2026

docker run -p 8080:8080 hapiproject/hapi
docker run -p 8443:8443 -p 6661:6661 openintegrationengine/engine
java -jar synthea-with-dependencies.jar -p 100 --exporter.fhir.use_us_core_ig=false
mllp_send --loose -f adt.hl7 -p 6661 localhost
java -jar validator_cli.jar p.json -version 4.0.1 -ig hl7.fhir.ca.baseline

Load Synthea into HAPI by POSTing hospitalInformation*, practitionerInformation*, then patient bundles. OIE logs in as admin/admin; pip install hl7 gives mllp_send; for Canadian patients put synthea-international's ca/ first on the classpath.
