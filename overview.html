Course Overview

Before you start (prework, ~4 h)

Install Docker, JDK 17+, Python 3, Node 20 and the .NET 8 SDK. Watch MIT Missing Semester's shell, git and development-environment lectures. Create one git repo for the whole course. The commands for the lab are on the lab setup page.

By the end you can

  • Trace an encounter and say who recorded each fact, and where it lives in FHIR.
  • Answer clinical questions in SQL and jq, and explain why two answers differ.
  • Receive HL7 v2 over MLLP, ACK honestly, and upsert FHIR without duplicates.
  • Validate FHIR against US Core or CA Baseline in CI.
  • Keep PHI out of logs, prompts and git, and prove it with tests.
  • Ship a stack a reviewer can run in 10 minutes, with a runbook and an interface spec.

What you build

Suggested repo layout

health-it-semester/
  katas/        week 0: java/  csharp/  python/  typescript/
  data/         Synthea output (git-ignored, regenerated with a fixed seed)
  hl7/broken/   week 3 broken message set + expected results
  bridge/       MLLP listener, mapper, tests
  oie/          exported channel XML (week 6)
  docs/         encounter story, glossary, interface spec, runbook
  ci/           validator, PHI canary and replay checks
